**Category:** Reverse Engineering  
**Difficulty:** Easy

## Description

The binary takes a number as a command-line argument. Most numbers give you nothing. Only one magic number unlocks the flag.

A decompiler like Ghidra or IDA Pro turns raw assembly into readable C-like code. Use one to find the secret number and recover the flag.

## Flag

`Spark{d3c0mpil3r_is_7h3_k3y}`
