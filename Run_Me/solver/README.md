# Writeup - Run_Me

**Author: becem69 😝**

## Summary

The flag is printed directly to stdout when you execute the binary. No reversing needed.

## Solution

Give the binary execute permission and run it:

```bash
chmod +x Run_Me
./Run_Me
```

Output:

```
Spark{7ry_70_run_furs7}
```

## Flag

`Spark{7ry_70_run_furs7}`
